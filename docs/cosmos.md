# 实验 03 · 从街角到黑洞

## 方案选择：自建 3D，不嵌 Google Earth

这个实验主要讲跨尺度空间关系和黑洞互动，不是寻找真实街道地址。采用项目现有的 **Three.js r187**，无需在线地图、账号或额外 API 密钥，能统一控制天体、轨迹、交互和离线 EXE。

Google 的 Photorealistic 3D Tiles 更适合真实地理街景，需要联网服务、认证与计费设置；即使地面部分接入它，太阳系、银河系和黑洞仍需自建。因此本版采用自建示意街区。日后如确实需要“从自家门口起飞”，可以另做可选联网地图模式，但本版没有实现该功能。[Google 官方配置说明](https://developers.google.com/maps/documentation/tile/get-api-key)、[用量与计费说明](https://developers.google.com/maps/documentation/tile/usage-and-billing)。

## 3.1：一镜远航，不再逐章换景

交互参考 [星海奥德赛](https://stellar.guushu.com/) 的滚轮跨尺度体验；使用现有 Three.js 独立实现，没有复制其 AGPL 源码、星表或素材。仍可离线运行。

一条连续路线：**街道 → 区域地形 → 地球与月球 → 太阳系 → 恒星邻域 → 银河系 → 星系群与宇宙网**。

- 画布中滚轮向下持续拉远，向上沿原路回到地球；拖动仅改变观察方向。
- “开始升空”自动沿这条路线远航，到宇宙尺度停止，不自动跳进黑洞。
- 进度条可连续拖动；六个尺度刻度是平滑移动的目的地，不再直接切换场景。
- 镜头尺度读数自动在 m / km / AU / 光年 / 百万光年间换算；该数值表示观察距离量级，不是飞船高度、速度或精确测距。
- 小天体放大为可见标记；太阳系内轨道在拉远过程中逐渐增强分离度，以免内行星全都挤在太阳内。不是同一固定比例的宇宙模型。
- 行星使用近似周期的加速圆轨道，不是今日星历。太阳和八大行星始终保留，远离后缩成一个太阳系标记。
- 恒星邻域、银河结构、星系群和宇宙网都是程序生成的教学示意；宇宙网不是巡天测量，也不表示宇宙的边界。

### 为什么不会黑屏切章

`cosmos-core.js` 在对数距离上做共享斜率的 Hermite 插值；`voyage-scene.js` 给所有层使用**同一个米/场景单位比例与浮动原点**。地面、地球、太阳、太阳系与银河中心的锚点持续计算，不在章节边界重置相机。相邻细节层在同一坐标系重叠淡化，天空颜色连续变化。街道到地球之间增加曲面区域地形，避免尺度空档；地面原点向地心移动的时机经过“相机不能进入地球”测试。

界面标题随尺度更新，但不会隐藏全部物体、出现全屏黑色过渡或重新创建渲染器。极大的空间跨度仍然做了教学性的细节管理与标记放大，不宣称从真实地址到宇宙的摄影录像。

黑洞为一个明确的**局部观察窗口**，不占用远航缩放条末端。任何尺度都可打开；画面叠入黑洞近景，返回时恢复原来的远航位置。本次访问中的样本保留，退出近景后停止积分；切换到其他实验时只保存远航进度和设置，不保存样本。

## 黑洞互动

- 点击样本按钮会投放在默认位置，也可从右侧拖到视口中指定位置。
- 画面里的样本可以再拖动摆放；松手时根据选项重新设置初速度。
- **轻轻放开**：初速度为零，会在模型中央引力下下落。
- **给它侧向速度**：近似圆轨道速度，可以保持环绕，说明黑洞不是把一切自动吸进去的吸尘器。
- **演示靠近 / 演示环绕**：可重复的课堂摆法；清空样本不改变黑洞视角。
- 最多同时保留 8 个未越界样本。暂停可观察形变。
- 接近时会拉伸、出现碎片示意，并在靠近视界时变暗、变红。计数是模型坐标时间中的越界，不是外部观察者看到它瞬间消失。

### 三种计算需要区分

**运动模型**：无自引力、无天体碰撞、无流体的测试粒子，采用牛顿中央引力和 velocity-Verlet 数值积分。远处的环绕能保持能量；接近事件视界时不是准确的广义相对论轨道。

**潮汐模型**：以 `r_t ≈ R_* (M_BH/M_*)^(1/3)` 和 `Rs = 2GM/c²` 估计相对潮汐位置。拉伸和粒子碎片是视觉解释，未求解真实天体破裂及吸积盘流体过程。参数为近似值，省略恒星结构、黑洞自旋和撞击轨道影响。

**视觉模型**：GLSL 中沿光线进行近似球对称引力偏折，检测与薄发光盘的交点，生成折叠的盘面图像、暗影、视觉多普勒亮暗和辉光。不是完整 Schwarzschild / Kerr 时空光学，不具有科研精度；背景天体样本本身也未做完整相对论透镜渲染。

画面以 Rs 归一化，Sgr A* 与 M87* 看起来的大小相近，但实际视界半径并不相同。模拟时钟不是物理秒。更换黑洞会改变实际半径和潮汐位置，不代表同尺度下两者质量相等。

## 几个需要讲准确的事实

- 太阳系有八大行星，不是“八大恒星”；冥王星是矮行星。太阳系整体绕银河中心一周约需 2.3 亿年。[NASA 太阳系概览](https://science.nasa.gov/solar-system/solar-system-facts/)
- 行星参数为简化的公开近似值，未使用今日星历。[NASA 行星数据表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)
- 《星际穿越》是 2014 年电影，Gargantua 为虚构黑洞。其外观是科学启发的影视渲染，不能当作望远镜照片。[EHT 对电影黑洞的说明](https://eventhorizontelescope.org/faq/how-realistic-are-movie-depictions-black-holes-eg-interstellar)、[原始渲染研究论文](https://arxiv.org/abs/1502.03808)
- EHT 于 2019 年公布 M87*、2022 年公布 Sgr A* 首张图像；2024 年的 Sgr A* 图像展示的是偏振信息。[ESO / EHT 2022](https://www.eso.org/public/science/EHT-MilkyWay/)、[ESO 2024](https://www.eso.org/public/news/eso2406/)
- 发光的是吸积物质，不是事件视界本身。背面的盘面会因光线弯曲出现在暗影上方 / 下方。[NASA / Jeremy Schnittman 可视化](https://svs.gsfc.nasa.gov/13326/)
- 黑洞不是宇宙吸尘器；同质量物体在远处的引力并不会只因压成黑洞就突然增大。[NASA Imagine the Universe](https://imagine.gsfc.nasa.gov/science/objects/black_holes2.html)

## 素材与工程

NASA 官方 3D Resources 的地球全球贴图和月面照片均本地存放，具体文件来源见 `web/assets/cosmos/SOURCES.md`。月球照片仅作表面材质示意，不是全球测绘贴图；其他行星材质、街区、星系与星点全部程序生成。无电影截图、无 Google 地图、无运行时网络请求。

- `web/cosmos-core.js`：章节、近似天体参数、Rs / 潮汐估计、粒子积分、存档验证。
- `web/src/cosmos.js`：连续镜头、黑洞观察窗口、拖放与界面。
- `web/src/voyage-scene.js`：共享尺度 / 原点、区域地形、恒星邻域和多级星系结构。
- `web/src/blackhole-shader.js`：光线偏折和发光盘着色器。
- `web/vendor/cosmos.bundle.js`：已打包的本地运行脚本。
- `tests/cosmos.test.cjs`：独立模型测试。
- `tests/browser-cosmos.check.js`：浏览器交互验证函数。

位置章节与显示设置自动保存；临时投放的样本和相机自由视角不保存。切到其他实验时停止远航并暂停本实验；返回后可手动继续。原有两个实验的存档键不变。
